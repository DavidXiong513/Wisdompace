# 居家养老还是去养老院 · 规划方案

> 模块位置：第三篇「清楚交代」B 位（「晚年花费测算」之后、「生前预嘱」之前）
> 版本：v0.2 讨论稿 ｜ 2026-11-28
> 资料基础：思考熊《五级护理》《什么是养老院/护理院》《现场参访梳理》三篇笔记 + 公开政策与法条核验

---

## 一、四个设计判断（先说结论）

**判断 1：不做二元选择，做三档分流。**
「居家 / 机构」是个假二选一。9073 格局本身就是三档（90% 居家、7% 依托社区、3% 机构），社区这一档是真实存在、政策在推的（家庭养老床位、六助服务、探访关爱）。工具输出必须是 **居家 → 居家+社区支持 → 机构** 三档。

**判断 2：不做打分排名，做「硬约束触发」。**
不适居家的判断不是"机构得分更高"，而是"家里出现了扛不住的硬条件"。模型分两层：硬约束清单（红灯）+ 五维评估（黄灯/绿灯）。**默认居家，机构是触发出来的结论。**

**判断 3：把"紧急签字能力"从身体维度里拆出来，单独成为一维。**
原因见第二节。

**判断 4（v0.2 新增）：身份分流放在最前面，它不是可选项。**
「本人来咨询」和「子女代父母来咨询」是两种完全不同的产品：人称不同、敏感问题的问法不同、报告的行动主体不同、照护者耗竭这一维的权重不同。开局第一题就问，成本最低、收益最大。

## 二、三条事实核验（含一处需要更正的前提）

### 2.1 「无人签字，120 不出车」不成立

- 《院前医疗急救管理办法》要求急救中心接到呼救后立即派车，**不以家属签字为出车前提**。
- 《民法典》1220 条 + 《医师法》27 条：抢救生命垂危患者等紧急情况，**不能取得患者或其近亲属意见时，经医疗机构负责人或授权负责人批准，可立即实施医疗措施**，医疗机构不因此担责。司法解释列明"近亲属不明／联系不上／拒绝表态／意见不一致"均属"不能取得意见"。

**"没人签字"不会挡住抢救。** 但担忧指向的风险真实存在，只是位置不同：

| 真实缺口 | 场景 | 后果 |
|---|---|---|
| **无人发现** | 独居跌倒、晕厥、卒中无人知晓 | 错过黄金抢救时间——**独居最致命的一条** |
| **无人陪护** | 无抬运、陪同、办手续、垫付 | 救治延迟、出院无人接 |
| **无人代理（非紧急）** | 择期手术、特殊检查、转院、康复方案变更、入住机构签协议 | **不受 1220 条豁免**，必须有签字人 |

**结论**：把"签字"重新定位为「医疗代理缺口」，归入应急授权维度，并直接指向站内已有的「意定人选择」。

### 2.2 四套分级并存，禁止做数字映射

这是本项目最容易出错的地方，比户口差异更麻烦：

| 体系 | 分级 | 谁在用 |
|---|---|---|
| 思考熊五级护理 | 独立生活 + 一级～五级 | **机构报价与照护强度**，最贴近用户感知 |
| GB/T 42195-2022 国标 | 能力完好／轻度／中度／重度／完全失能（5 级）；4 个一级指标 + 26 个二级指标 | 政府补贴、公办机构入住 |
| 长护险失能等级（国家医保局） | 0 基本正常～5 重度Ⅲ（6 档） | 领长护险待遇 |
| 上海老年照护统一需求评估 | 1～6 级 | 上海本地长护险与补贴 |

**四套等级之间没有一一对应关系。** 例如上海说"评估等级二至六级可享长护险"，国家医保局说"3–5 级重度失能可享"——数字看着像，含义不同。

**工具硬规则：**
1. 主叙事用五级护理（可感知）；
2. 另外三套只做**对照标注**，不做自动换算；
3. 凡出现"你的等级可以领 X"，一律加"需经当地正式评估确认"。

### 2.3 价格资料内部冲突 → 已作废（v0.3）

原记录的两处冲突：护理院自费 5000–7000 vs 6000–8000；养老院 5000–9000 vs 5000–10000。

**这两个冲突不再需要裁决**——见 4.1，产品已决定不给价格区间。冲突本身也侧面印证了判断：同一类机构在不同资料里差 2000 元，说明这类数字的置信度不足以承载"预算判断"这个用途。

## 三、模型结构（四个 Stage）

```
Stage 0  身份分流（本人 / 子女代做 / 本人已无法作答）
   ↓
Stage 1  硬约束清单（红灯）──命中──→ 直接进 Stage 3
   ↓ 未命中
Stage 2  五维评估 ──→ 报告 A《居家养老条件评估》
   ↓ 用户主动选择 或 红灯触发
Stage 3  护理等级自查 + 机构类型匹配 ──→ 报告 B《机构类型建议》
```

### 3.0 Stage 0：身份分流（第一题）

| 选项 | 人称 | 专属追问 | 影响 |
|---|---|---|---|
| **A 我是本人** | 我 | 独处时的安全感、对机构的态度、最怕失去什么 | 报告写给"我自己"，行动主体是本人 |
| **B 我是子女/家属** | 他/她 | 你的照护负担（时间/钱/健康/情绪四项）、是否同城、每周可投入小时数 | **H6 照护者耗竭升为一等维度**，报告写成"家庭会议材料" |
| **C 本人已无法表达意愿** | 他/她 | 不问意愿，只问现状 | **选项 C 本身就是 H1 的强信号**，直接提示认知评估与意定监护现状 |

**关键洞察：选 C 这件事本身就是一个诊断结果。** 一个人已经无法表达意愿，说明认知或意识已受损，居家照护的可行性判断逻辑要整体切换——此时不再问"他愿不愿意去机构"，而要问"现在谁在照护、撑得住吗、有没有代理人"。

**实现建议**：同一套题 + 人称模板 + 少量专属题，不做两套流程。否则维护成本翻倍，且三语要维护三遍。

### 3.1 Stage 1：硬约束清单（红灯）

| # | 硬约束 | 判据 | 指向 |
|---|---|---|---|
| H1 | 认知障碍已到不可独处 | 走失史／误服／忘关火／出门迷路，且无 24 小时看护 | 护理院记忆照护单元 |
| H2 | 需 24 小时不间断照护（三级及以上） | 穿衣进食修饰需协助、行走转移需轮椅、卧床 | 护理院 |
| H3 | 需定期专业医疗处置 | 血透、腹透、管路维护、伤口换药、专业康复 | 护理院／康复医院 |
| H4 | 独居 + 无「4 小时内可达」者 + 有跌倒/晕厥/心脑血管史 | 关键是**到达时间**，不是"有没有子女" | 居家改造或转机构 |
| H5 | 需非紧急医疗决策但无代理人 | 无人可签择期手术、特殊检查、转院、机构协议 | 先补意定监护 |
| H6 | 家庭照护者已耗竭 | 照护者辞职、抑郁、自身健康崩塌 | 喘息服务／转机构 |

### 3.2 Stage 2：五维评估

| 维度 | 看什么 | 不达标时的补法 |
|---|---|---|
| 1 身体与认知 | 五级护理自评落在哪级；是否有 MCI 迹象 | 一级二级可撑；三级起需组合方案 |
| 2 身边有没有人 | 同住者、15 分钟可达者、4 小时可达者、是否同城 | 紧急联络人、探访关爱、智能监测 |
| 3 房子能不能住 | 楼层电梯、扶手防滑、门槛、照明、独居 | 适老化改造 |
| 4 钱与支付能力 | 月照护预算、是否够长护险/补贴资格、本地有无家庭养老床位 | 长护险申请、六助、家庭养老床位 |
| 5 意愿与心理 | 机构接受度、社交需求、离家执念 | 意愿优先于模型结论 |

**核心判据（来自笔记，原样进入结果页）**：
> 一级、二级护理阶段，靠老伴／子女／钟点工 + 长护险还能勉强支撑；**一旦进入三级及以上，居家压力和难度指数级上升**，短时间还行，时间一长必然出现问题。要么能请到 24 小时靠谱陪护（基本可遇不可求），要么就得考虑机构。

## 四、机构类型与匹配

**本节不含价格数字**，理由见 4.1。

| 类型 | 性质 | 医疗能力 | 计价结构 | 适合 |
|---|---|---|---|---|
| 养老院 | 生活照料机构 | 内设基本医疗、可刷医保；**不能抢救** | 床位费 + 护理费 + 餐费；押金多为 1–3 个月 | 自理～二级 |
| 护理院 | **医疗机构** | 医生护士药剂师齐全，**能抢救** | 床位费 + 护理费 + 医疗自费部分；医保按住院/门诊统筹结 | 三级以上、医疗依赖高 |
| 康复医院 | 医院（多为二级资质） | 专业康复（中风后、骨折后） | 按疗程计费，医保覆盖比例高于养老机构 | 病后短期集中康复 |
| CCRC／康养社区 | 高端养老机构 | 内设医疗为主，部分扩护理院 | 会员费/门槛费 + 月服务费，退费条款复杂 | 活力老人、预算充裕 |
| 认知症照护单元 | 养老院/护理院**内的专区** | 记忆照护、封闭管理 | 随所属机构，在同类护理费上加价 | 五级护理／失智 |

> 认知症照护单列，是因为五级护理把"记忆照护"立为一档，但四类机构里没有对应载体——它实际是专区。结构差异必须说清，否则用户会去找"认知症照护院"而找不到。

### 4.1 为什么不给价格区间（v0.3 决策）

**结论：不写月费区间，改给「量级 + 计价结构 + 浮动因素 + 问价清单」。**

三条理由：

1. **静态区间写下即过期。** 同一家机构、同一年，报价随入住率浮动——空床多时打折、甚至免床位费；住满了就涨，还可能收排队费。差距可达两三成。任何写死的区间都不成立。
2. **假精确的代价是信任。** 用户拿"5000–8000"去问，问到 9500，不会判断为"行情涨了"，而会判断为"这工具不准"。估算信息的价值，低于它造成的信任损耗。
3. **但完全不给锚，等于把人赤手空拳送进谈判。** 所以要给的是**不会过期的信息**：

| 给什么 | 为什么稳定 |
|---|---|
| **量级**（数千元/月 · 万元级/月 · 2 万+/月） | 类型之间的数量级差不随行情变化，护理院与康养社区差一个量级是结构性的 |
| **计价结构**（床位费 + 护理费 + 餐费 + 押金/会员费 + 医疗自费） | 结构远比价格稳定，且这是用户唯一能逐项比对、逐项砍价的地方 |
| **浮动因素**（入住率、护理等级、房型、是否医保定点） | 解释"同一家为什么问两次两个价"，避免用户被话术带走 |
| **问价清单**（见报告 B） | 把"预算够不够"转成"我知道该问哪几件事" |

**措辞红线**：

- 禁止出现「上海均价 X 元」「该类型一般 Y–Z 元」这类**看似报价**的表述；
- 可以说「量级上属于数千元级」「比养老院高一档」，但不落到具体数字；
- 任何页面必须挂一句：**价格以当地机构当期报价为准，且随入住率浮动**。

**匹配用排除法**（预算轴已改为量级筛选，不做精确比较）：

```
Step 1 护理等级 → 排除（三级以上排除养老院）
Step 2 医疗需求 → 排除（血透/管路/常叫120 → 留护理院；病后康复 → 康复医院优先）
Step 3 预算量级 → 只筛掉明显不匹配（如预算数千元级 / 康养社区为万元级起），
                  不比较具体金额；不足时提示"需长护险/补贴/降档"，不直接排除
Step 4 城市档位 → 只影响量级描述与声明，不做系数换算
Step 5 剩 1–2 类 → 结论 + 参访提问清单 + 问价清单
```

### 4.2 实地观察样本：上海·新东苑快乐家园（2026-11-28）

用户实地参访记录。**单一样本，仅用于校准量级描述，不可外推为行业价格。**

| 项 | 观察 |
|---|---|
| 机构定位 | 上海高端康养社区（CCRC 类） |
| 房费（单间／双人间） | 约 1 万–1.5 万元／月 |
| 房费（两室／三室两厅） | 约 2 万–3.3 万元／月，按面积定，户型越大多数越高 |
| 伙食费 | 另计，约 1500–1600 元／月（人均 50–60 元／天，可按天折算） |
| 照护费 | 另计，按护理等级分档 |
| 押金／会员费 | 另有，条款复杂 |

**三条可直接用的结论**：

1. **「区间」对高端社区彻底失效**——同一家社区内部，单间与三室两厅差三倍以上。任何写成「2 万起」或「1–3 万」的区间，都会同时误导低预算与高预算两端的人。
2. **报价必须是分项的**：房费（按户型）＋ 伙食费（按天）＋ 照护费（按护理等级）＋ 押金/会员费 ＋ 医疗自费。问「一个月多少钱」得到的一定是残缺答案。
3. **高端 ≠ 全包**：房费高的社区，照护费往往另外按等级加收，失能后总价会上一个台阶。这一点最容易在销售话术里被模糊掉。

→ 已把康养社区的量级从「2 万元级／月起」校正为**「万元级到数万元级／月，按户型与面积浮动；伙食、照护另计」**。

## 五、支付与政策口径（v0.2 新增，本项目最容易写错的一节）

### 5.1 三条支付线，别混

| 支付线 | 主管 | 对象 | 上海实际口径 |
|---|---|---|---|
| **长期护理保险** | 医保局 | 失能人员的照护服务 | 60 周岁+、评估等级 2–6 级；**居家上门支付 90%**（2/3 级每周 3 次、4 级 5 次、5/6 级 7 次，每次 1 小时）；**社区日间 85%**；**养老机构照护 85%** |
| **养老服务消费补贴** | 民政局 | 中度以上失能老人 | 2026-01-01 起，每月最高 **800 元**电子消费券；**居家抵 50%、社区/机构抵 40%**；以**居住地**为准不限户籍；**可与长护险叠加**抵自付部分；当月有效 |
| **基本医疗保险** | 医保局 | 医疗行为 | **护理院属医疗机构，主要走医保**（多为一级医院待遇，个别二级） |

**用户要点确认**：
- 养老院 → 主要靠**长护险 + 养老消费补贴**；
- 护理院 → 主要靠**医保**（住院/门诊统筹）；
- **但不是互斥**：护理院若同时是长护险定点，也可能叠加机构护理待遇；养老院内设医疗机构也可能刷医保。**所以文案写"主要支付渠道不同"，不写"只能用某一种"。**

### 5.2 措辞规范（硬要求）

| 禁止 | 改为 |
|---|---|
| "可以报销长护险" | "在已开展长护险试点的地区，通常可通过定点机构结算；**是否可结算、结算比例，以当地医保部门口径为准**" |
| "上海可报 800 元" | "以上海为例，中度以上失能老人可申请每月最高 800 元养老服务消费补贴" |
| "护理院用医保，养老院用长护险" | "两者主要支付渠道不同：护理院以医保为主，养老院以长护险与养老补贴为主；具体叠加情况各地不同" |
| "评估 X 级可领 Y 元" | "评估 X 级通常可享…；**各地待遇标准不同，且随年度调整**" |

**必须同时挂的两条提示**：
1. 各地政策差异大、逐年调整，**以当地医保局、民政局最新口径为准**；
2. **参保类型与户籍性质会影响待遇**：职工医保与城乡居民医保筹资与待遇不同，城镇与农村在服务供给密度上差异更明显（不是"农村户口不能享受"，而是"可及的服务更少"）。

### 5.3 数据建模

政策不写死在代码里，做成一张可替换的政策表：

```ts
type PolicyCell = {
  cityTier: CityTier;
  channel: 'ltc' | 'subsidy' | 'medical';
  appliesTo: InstitutionType[];
  ratioText: string;        // 例："基金支付约 85%"
  capText?: string;         // 例："每月最高 800 元"
  conditionText: string;    // 例："评估等级 2–6 级"
  note: string;             // 差异提示
  source: string;           // 出处，必须可追溯
};
```

规则：**只有上海一格填了真实数据，其余城市显示通用规则 + "以当地为准"**。没有数据的格子宁可不填，不估算。

## 六、两份输出物

### 报告 A《居家养老条件评估》

1. **三色结论**：绿灯（可居家）／黄灯（需补 N 项）／红灯（触发硬约束）
2. **五维雷达 + 缺口清单**：哪项不达标、怎么补、**谁来做**（按身份分流决定行动主体）
3. **居家注意事项**（主交付物）：适老化改造清单、六助服务对接、长护险与补贴申请路径、紧急联络机制（4 小时可达者）、医疗代理安排（指向「意定人选择」）
4. **转介条件**：H1–H6 任一出现时该重新考虑机构
5. **观察指标**：半年后回来看哪几项（与「今生复盘」一致）

### 报告 B《机构类型建议》

1. 锁定 1–2 类 + 为什么排除其他（逐步可解释）
2. 价格区间（上海样本基准 + 城市档位说明）+ 可能适用的支付渠道
3. 五级护理对照表（自评等级 → 该类型的护理区）
4. **参访提问清单**（8 组 23 问 + 现场技巧，可勾选、可打印）
5. 签约红线：口头承诺不写进合同一律不信；会员卡/大额预存要警惕
6. 供给声明：「以下类型需确认本地是否有供给」

## 八、边界与免责

1. 不做医疗诊断，不替代 GB/T 42195-2022 正式评估、长护险失能等级评定。
2. 不推荐具体机构，不做排名，不接机构广告。
3. 价格为上海样本估算，不代表当地实际；类型供给需本地确认。
4. 政策以当地最新口径为准，工具只讲规则不承诺金额。
5. **意愿优先**：模型结论与用户意愿冲突时，只陈述风险，不替人做决定。

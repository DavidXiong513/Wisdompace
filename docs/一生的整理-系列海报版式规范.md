# 《一生的整理》工具海报 · 版式规范

> 依据 `《一生的整理》工具海报合集` 现存 24 张工具海报 + 8 张章节封面反向测量得出。
> 样本基准：`3-6 意定人托付-ta-worth-trust-poster.jpg`（1080×1920）。
> 本文件用于新增工具海报时严格对齐，避免出现「另一套风格」。

## 一、画布与基础量

| 项 | 值 |
|---|---|
| 工具海报画布 | **1080 × 1920**（16:9 竖版，全部 24 张一致） |
| 章节封面画布 | 1080 × 1200（不在本规范范围） |
| 左右内容边距 | **58px**（内容宽 964，右侧留 59） |
| 主字体 | **思源黑体 Noto Sans SC**，标题 weight 900，正文 400/500 |
| 底纹 | 40px 正方网格，线色约 `rgba(60,40,30,.035)`，极淡 |
| 背景 | 暖米渐变 `#F8F4EB → #F0E4D8`，中下部略深 |

**禁止**：宋体/衬线体做标题、插画主视觉、单色方案。系列是「纯排版 + 一个强调色」的视觉逻辑。

## 三、组件规范

### 1. Header
- 左：直径 60 的细线圆环（stroke 1.5，环内一条横线）＋「一生的整理」34px/700 ＋「LIFELONG ORGANIZING」13px，字距 .16em，灰
- 右：右对齐两行——「坦然告别 · 清楚交代」18px 灰；「WISDOMPACE.COM」20px 灰，字距 .12em

### 2. 药丸标签
白底（半透明）＋ 1px 强调色描边 ＋ 左侧 8px 实心圆点 ＋ 文字 26px/700 强调色。内容＝工具名（4–6 字）。

### 3. 英文小标
全大写，19–20px，字距 .2em，强调色（或 60% 透明度）。格式：`KEYWORD · KEY QUESTION?`

### 4. 主标题
- 两行，112px/900，行高 ≈ 0.98，行末标点照排（「，」「？」）
- 第二行含 **1 个强调词**（3–4 字），换强调色
- 强调词下压一条淡色荧光笔块（高约 26px，透明度 .18，压在字底）
- 语气规则：**观点句 / 反问句**，不是功能描述。已有样本——「把命托付给谁，不能只凭感情」「从退休到离世，我需要准备多少钱？」「最后一程，我要自己说了算」

### 5. 副标题
34px，破折号 `—` 起头，一句话说明「这张海报帮你做什么」，不超过 30 字。

### 6. 深色四步卡
- 底：强调色的极暗低饱和版本（如 `#352226`、`#202E3B`），圆角 28，内边距 70/50
- 标题 44px/700 白；副标 24px 60% 白
- 右上胶囊：细描边 60% 白，20px，写耗时或规格（「1–5 分钟」「六步填完」）
- 四步 2×2：编号 01–04（22px 灰），标题 34px/700 白，说明 22px 65% 白
- 行间分隔线 `rgba(255,255,255,.12)`
- 卡底一句居中小字 22px，后半句用提亮的同类色（如 `#C08A8A`）加粗

### 7. 四宫格白卡
2 列 × 2 行，单卡 460×90，圆角 16，白底微暖。结构：强调色圆点 6px ＋ 标题 28px/700 ＋ 说明 22px 灰。标题写「得到什么」，不写功能名。

### 8. 分隔短句
34px 居中，句式 `— X 是 Y，不是 Z —` 或 `— 不是 A，而是 B —`，两侧各一条短横线。

### 9. 二维码大卡
- 卡片 `#FDF6EE`，圆角 24，宽 964（通栏）
- 白框 342×342，圆角 24，内边距 24，二维码 ≈ 294
- `SCAN OR LONG-PRESS` 19px 字距 .3em 强调色
- 引导句 44px/900，后半截换强调色：`扫码或长按识别，<动作>`
- 说明行 24px 灰：`微信内长按二维码图片即可识别 · 相机或「扫一扫」同样可用`
- 两个胶囊 32px 高：浅强调色底 + 圆点 + 20px 文字。固定为「无需登录即可用」「数据不出浏览器」一类的事实承诺

### 10. 页脚
左：一句凝练收尾（22px 灰）；右：`一生的整理 · 清楚交代`（22px，后半略浅）。

## 四、配色规则

每张海报**只用一个强调色**，深卡底色由它派生（同色相、明度压到 8–12%、饱和度降到 15% 左右）。

已确认样本：

| 海报 | 强调色 | 深卡底 |
|---|---|---|
| 3-3 晚年花费测算 | `#95482C` 砖红 | `#402E24` |
| 3-4 生前预嘱 | `#2F4463` 藏蓝 | `#202E3B` |
| 3-6 意定人托付 | `#7C353D` 酒红 | `#352226` |

同一篇章内相邻两张不重复色相，保持「一篇之内有变化、一套之内同一家族」。

## 五、文案结构（固定六句）

1. 主标题＝观点句（两行，第二行带强调词）
2. 副标题＝这张海报替你做什么
3. 深卡＝四步是怎么走的 + 一句免责式的收束
4. 四宫格＝你拿到什么（结果物，不是功能）
5. 分隔句＝一句态度
6. CTA＝动作 + 两个事实承诺

## 六、新增海报检查清单

- [ ] 1080×1920，边距 58
- [ ] 标题 Noto Sans SC 900，两行，第二行有强调词 + 荧光笔底
- [ ] 全文只有一个强调色，深卡由它派生
- [ ] 深卡四步为 2×2，编号 01–04
- [ ] 四宫格是「得到什么」不是「有什么功能」
- [ ] 二维码 ≥ 294px，白框 ≥ 342px，成品整图 `cv2.QRCodeDetector` 能解出 URL
- [ ] 「扫码」「长按识别」两句话都出现
- [ ] 页脚左右分列

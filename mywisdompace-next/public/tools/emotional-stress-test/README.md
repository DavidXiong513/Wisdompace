# 心理情绪压力自测 (emotional-stress-assessment)

一个专业的心理状态自测工具，结合情绪状态自评量表、紧张状态自评量表和生活压力事件回顾，提供全面的情绪、紧张、压力三维心理状态综合评估。

## 功能特点

- **三模块综合评估**：情绪评估 + 紧张评估 + 生活压力回顾
- **5级综合评估**：科学的状态等级评估（情绪 × 紧张 × 压力三维交叉）
- **个性化建议**：基于具体症状和事件的5级分层调节意见
- **温和提醒**：状态值得关注时自动显示调节建议
- **多种使用方式**：HTML交互界面、Python计算引擎、Skill调用
- **隐私保护**：所有数据保存在本地，不上传服务器

## 评估原理

### 情绪状态自评量表
- **20道标准题目**：评估最近一周的情绪状态
- **4级评分**：偶或无(1分)、有时(2分)、经常(3分)、持续(4分)
- **反向计分**：10道反向题（第2,5,6,11,12,14,16,17,18,20题）
- **分级标准**：良好(<40) / 稍有波动(40-49) / 值得关注(50-59) / 建议关注(≥60)，参考线40分

### 紧张状态自评量表
- **20道标准题目**：评估最近一周的紧张不安程度
- **4级评分**：偶或无 / 有时 / 经常 / 持续
- **反向计分**：5道反向题（第5,9,13,17,19题）
- **分级标准**：良好(<50) / 稍有波动(50-59) / 值得关注(60-69) / 建议关注(≥70)，参考线50分

### 生活压力事件回顾
- **65项生活事件**：涵盖家庭、工作学习、社交、健康等领域
- **LCU压力分数**：衡量事件带来的心理压力
- **6大分类**：家庭、工作学习、社交、健康、法律、经济
- **时间范围**：过去一年内发生的事件
- **LCU分级**：压力较低(<150) / 有一定压力(150-300) / 压力较大(300-450) / 压力较大(>450)

### 综合评估（三维矩阵）
- **5级综合评估**：等级1(良好) → 等级5(建议关注)
- **交叉分析**：情绪状态 × 生活压力水平
- **特殊关注**：
  - 消极想法关注（第19题≥3分）
  - 持续性状态关注（≥10题选高频）
  - 压力过载检测（压力高+情绪值得关注以上）

## 使用示例

### 通过HTML界面使用
1. 打开 `interactive-assessment.html`
2. 按照4个步骤完成测评：
   - 步骤1：阅读说明
   - 步骤2：完成情绪状态测评（20题）
   - 步骤3：完成紧张状态测评（20题）
   - 步骤4：勾选生活压力事件
   - 步骤5：查看综合报告
3. 可保存或打印报告

### 通过Skill调用
当用户在WorkBuddy中提到以下关键词时触发：
- "心理自测"
- "情绪测试"
- "压力测试"
- "心情不好"
- "最近压力大"

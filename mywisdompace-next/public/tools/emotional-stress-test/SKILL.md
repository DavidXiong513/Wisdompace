# 心理情绪压力自测 Skill

## 概述

本Skill提供三维心理状态综合自测工具：

| 模块 | 名称 | 题目 | 用途 |
|------|------|------|------|
| **情绪评估** | 情绪状态自评量表 | 20题 | 评估最近一周的情绪状态 |
| **紧张评估** | 紧张状态自评量表 | 20题 | 评估最近一周的紧张不安程度 |
| **压力评估** | 生活压力事件回顾 | 65项 | 评估过去一年的生活压力 |

### 核心优势

1. **全面性**: 同时评估情绪、紧张和压力三个维度
2. **专业性**: 基于国际标准量表和中国本土化常模
3. **科学性**: 综合三维数据生成综合评估结果
4. **实用性**: 提供个性化建议和调节方案

## 工作流程

```
用户请求 → 欢迎引导 → 情绪测评(20题) → 紧张测评(20题) → 压力回顾(65项) → 综合分析 → 报告输出
```

### 详细步骤

#### Step 1: 欢迎与说明 (Welcome)

- 展示欢迎界面和动画效果
- 说明测评目的、时间和隐私保护
- 用户填写基本信息（可选）
- 进入情绪测评

#### Step 2: 情绪状态自评 (Step 1 of 3)

- 逐一展示20道题目
- 4级评分：1=偶或无, 2=有时, 3=经常, 4=持续
- 实时显示进度条
- 显示当前题号/总题号
- 完成 → 进入紧张测评

#### Step 3: 紧张状态自评 (Step 2 of 3)

- 逐一展示20道题目
- 4级评分：1=偶或无, 2=有时, 3=经常, 4=持续
- 包含5道反向计分题提示
- 实时显示进度条
- 完成 → 进入压力回顾

#### Step 4: 生活压力事件回顾 (Step 3 of 3)

- 分类展示6大类65项事件：
  - 家庭类 (28项)
  - 工作学习类 (21项)
  - 社交与其他类 (9项)
  - 健康类 (7项)
- 用户勾选过去一年经历过的事件
- 可多选，未选表示LCU=0
- 完成 → 进入结果分析

#### Step 5: 综合分析与报告

**计算模块**:
1. 情绪状态评分 + 维度分析
2. 紧张状态评分 + 维度分析  
3. 生活压力总分 + LCU分级
4. **三维综合评估** (情绪 × 紧张 × 压力)
5. 特殊关注检测

**输出内容**:
1. 三个模块的独立评分和等级
2. 五维度分析条形图（情绪、认知、躯体、人际、功能）
3. **三维综合评估**
4. 分级改善建议和调节方案
5. 个性化改善建议

## 评分规则

### 情绪状态自评量表

**基本信息**:
- 题目数: 20题
- 评分: 1-4分 (偶或无/有时/经常/持续)
- 反向计分题: **10道** - 第2,5,6,11,12,14,16,17,18,20题
- 计分公式: 原始分 × 1.25 = 标准分

**反向计分转换**:
- 选"4持续"→得1分
- 选"3经常"→得2分
- 选"2有时"→得3分
- 选"1偶或无"→得4分

**分级标准**:

| 级别 | 原始分 | 标准分 | 含义 |
|------|--------|--------|------|
| 良好 | <32 | <40 | 情绪状态良好 |
| 稍有波动 | 32-39 | 40-49 | 有轻微波动 |
| 值得关注 | 40-47 | 50-59 | 建议适当关注 |
| 建议关注 | ≥48 | ≥60 | 建议重点关注 |

**参考线**: 标准分 ≥40分

**五维度分类**:
1. **情绪感受**: 第1,3,4,8,19,20题
2. **躯体症状**: 第2,5,6,7题
3. **精神运动性**: 第9,10,11题
4. **认知功能**: 第12,13,14,15题
5. **人际关系**: 第16,17,18题

### 紧张状态自评量表

**基本信息**:
- 题目数: 20题
- 评分: 1-4分 (偶或无/有时/经常/持续)
- 反向计分题: **5道** - 第5,9,13,17,19题
- 计分公式: 原始分 × 1.25 = 标准分

**分级标准**:

| 级别 | 原始分 | 标准分 | 含义 |
|------|--------|--------|------|
| 良好 | <40 | <50 | 紧张状态正常 |
| 稍有波动 | 40-47 | 50-59 | 有轻微紧张感 |
| 值得关注 | 48-55 | 60-69 | 建议适当关注 |
| 建议关注 | ≥56 | ≥70 | 建议重点关注 |

**参考线**: 标准分 ≥50分

### 生活压力事件回顾

**基本信息**:
- 事件总数: 65项
- 时间范围: 过去一年
- LCU范围: 0-100+分/事件

**6大分类**:

| 分类 | 事件数 | 示例事件 |
|------|--------|----------|
| 家庭类 | 28项 | 结婚(+53),离婚(+65) |
| 工作学习 | 21项 | 失业(+47),退休(+45),升职(+29) |
| 社交其他 | 9项 | 好友离世(+37),搬家(+20) |
| 健康类 | 7项 | 患重病(+53),轻微外伤(+13) |

**LCU分级**:

| 级别 | LCU总分 | 说明 |
|------|---------|------|
| 压力较低 | <150分 | 生活平稳，压力可控 |
| 有一定压力 | 150-300分 | 存在中等压力 |
| 压力较大 | >300分 | 压力较大，需关注 |

## 综合评估算法

### 新版评估矩阵 (情绪 × 紧张 × 压力)

基于三个维度的组合进行综合评估：

**基础等级确定**:

| 情绪级别 | 紧张级别 | 压力 | 基础等级 |
|---------|---------|------|----------|
| 良好 | 良好 | 低压力 | 等级1 状态良好 |
| 良好 | 良好 | 中压力 | 等级2 稍有波动 |
| 良好 | 良好 | 高压力 | 等级3 值得关注 |
| 良好 | 稍有波动 | 低/中压 | 等级2 稍有波动 |
| 良好 | 稍有波动 | 高压力 | 等级3 值得关注 |
| 良好 | 值得/建议关注 | 任意 | 等级3-4 |
| 稍有波动 | 良好/稍有波动 | 低压力 | 等级2-3 |
| 稍有波动 | 稍有波动 | 中压力 | 等级3 值得关注 |
| 稍有波动 | 稍有波动 | 高压力 | 等级3-4 |
| 稍有波动 | 值得/建议关注 | 任意 | 等级3-4 |
| 值得关注 | 任意 | 低压力 | 等级3-4 |
| 值得关注 | 任意 | 中/高压力 | 等级4 建议调节 |
| 建议关注 | 任意 | 任意 | 等级4-5 |

### 特殊关注机制 (风险等级+1)

**以下任一条件触发时，基础等级 +1 (最高不超过等级5)**:

1. **消极想法关注**
   - 情绪评估第19题 ≥3分
   - 提示：可能存在消极想法

2. **持续性状态关注**
   - 情绪评估中 ≥10题选"经常"或"持续"
   - 或 紧张评估中 ≥10题选"经常"或"持续"
   - 提示：状态持续时间较长

3. **情绪-紧张双指标偏高**
   - 情绪标准分 ≥50分 AND 紧张标准分 ≥50分
   - 提示：情绪和紧张两方面都偏高

4. **高压叠加效应**
   - 压力高LCU事件 ≥3项 且 (情绪或紧张达到值得关注以上)
   - 提示：压力与状态相互影响

## 分级建议

#### 等级1: 状态良好
- **状态**: 整体心理状态良好
- **建议**: 保持健康生活方式
- **调节**: 无需特殊处理

#### 等级2: 稍有波动
- **状态**: 有轻微波动，基本正常
- **建议**: 
  - 注意情绪调节
  - 保持规律作息
  - 适度运动
- **调节**: 自我调节为主

#### 等级3: 值得关注
- **状态**: 存在一定程度的困扰
- **建议**:
  - 学习放松技巧（深呼吸、冥想）
  - 增加社交活动
  - 减少压力源
  - 关注睡眠质量
- **调节**: 建议自我调节2-4周，如无改善可咨询专业人士

#### 等级4: 建议调节
- **状态**: 状态值得关注
- **建议**:
  - 建议寻求专业心理咨询
  - 可考虑就诊评估
  - 与家人朋友沟通
  - 避免重大决策
- **调节**: 建议专业咨询

#### 等级5: 建议关注
- **状态**: 状态需要关注
- **建议**:
  - **建议寻求专业帮助**
  - 可以考虑精神科/心理科就诊
  - 不要独处，告知亲友
  - 与专业人士聊聊
- **调节**: 建议预约专业咨询

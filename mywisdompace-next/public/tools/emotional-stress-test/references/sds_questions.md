# 情绪状态自评量表 - 完整题目与计分规则

## 量表简介

**情绪状态自评量表** 是基于国际标准自评量表改编的心理状态评估工具，共20题，评估最近一周内的情绪状态。

## 评分标准（4级）

| 分数 | 频率定义 | 标准说明 |
|------|----------|----------|
| **1分** | 偶或无 | 一周一次都没有或偶尔几周一次 |
| **2分** | 有时 | 一周一到两次，不超过三次 |
| **3分** | 经常 | 一周三到五次 |
| **4分** | 持续 | 每一天 |

## 反向计分规则（10道反向题）

反向计分题：**2, 5, 6, 11, 12, 14, 16, 17, 18, 20**（共10题）

**计分转换规则**：
- 原始得分1分 → 转换后4分
- 原始得分2分 → 转换后3分
- 原始得分3分 → 转换后2分
- 原始得分4分 → 转换后1分

## 计分与分级

### 1. 原始分计算
- 正向题：直接计分（1-4分）
- 反向题：转换后计分（按反向规则）
- **原始总分范围**：20-80分

### 2. 标准分计算
```
标准分 = 原始总分 × 1.25
标准分范围：25-100分
```

### 3. 分级标准

| 标准分范围 | 情绪状态 | 建议 |
|------------|----------|------|
| **< 40分** | 良好 | 保持良好生活习惯 |
| **40-49分** | 稍有波动 | 适当调节，定期观察 |
| **50-59分** | 值得关注 | 建议适当关注 |
| **≥ 60分** | 建议关注 | 建议寻求专业帮助 |

### 4. 特殊关注
- **第19题 ≥ 3分**：触发消极想法关注提醒
- **≥10题选"经常"或"持续"**：触发持续性状态关注提醒

## 评估注意事项

### 有效性检查
1. **回答一致性**：相关题目答案应有一定一致性
2. **反向题验证**：检查是否理解反向计分逻辑
3. **极端回答**：全选1分或4分可能不可靠

### 结果解读要点
1. **不是诊断工具**：本量表用于自我了解，不能替代专业诊断
2. **结合时间因素**：状态持续2周以上需重视
3. **考虑环境因素**：近期生活事件可能影响得分
4. **综合评估**：需结合生活压力评估和其他信息

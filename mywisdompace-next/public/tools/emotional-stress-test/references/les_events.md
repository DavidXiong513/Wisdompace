# 生活压力事件回顾 - 完整事件与LCU分数

## 量表简介

**生活压力事件回顾** 是一个针对中国人群的生活压力评估工具，包含65项生活事件，评估过去一年内的生活压力水平。

## 评分标准

### LCU (Life Change Unit) 生活变化单位
- 衡量事件带来的心理压力和适应需求
- 分数越高，压力越大
- 累计LCU总分反映整体压力水平

### 时间范围
- **评估期间**：过去一年内
- **事件类型**：实际发生的事件
- **影响程度**：事件对个人的实际影响

## LCU分数参考等级

### 累计总分参考

| 累计LCU总分 | 压力水平 | 建议 |
|-------------|----------|------|
| **< 150分** | 压力较低 | 正常生活，定期观察 |
| **150-300分** | 有一定压力 | 注意压力管理，建议放松 |
| **> 300分** | 压力较大 | 建议减压，考虑咨询 |

## 评估与计分规则

### 1. 勾选规则
- 只勾选**过去一年内实际发生**的事件
- 不考虑预期或担心发生的事件
- 同一事件多次发生只计一次

### 2. 计分方法
```
总LCU分数 = ∑(所有勾选事件的LCU分数)
```

### 3. 特殊事件处理
- **正向事件**：如结婚、子女出生、怀孕等，虽然LCU分数高，但对状态影响可能不同
- **累计效应**：多个中等压力事件累加可能超过单个高压力事件
- **时间分布**：事件集中发生比分散发生压力更大

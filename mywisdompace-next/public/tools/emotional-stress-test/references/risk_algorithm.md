# 三维综合评估算法 (情绪 × 紧张 × 压力)

## 概述

本算法整合三个维度的数据，生成**5级综合评估结果**：

| 维度 | 模块 | 测评内容 | 分数范围 |
|------|------|----------|----------|
| **E** | 情绪状态 | 最近一周的情绪状态 | 原始分 20-80, 标准分 25-100 |
| **T** | 紧张状态 | 最近一周的紧张不安程度 | 原始分 20-80, 标准分 25-100 |
| **L** | 生活压力 | 过去一年的生活压力 | LCU 0-1000+ |

---

## 各维度分级标准

### 情绪状态等级 (E)

| 等级代码 | 标准分范围 | 名称 |
|----------|-----------|------|
| E0 | <40 | 良好 |
| E1 | 40-49 | 稍有波动 |
| E2 | 50-59 | 值得关注 |
| E3 | ≥60 | 建议关注 |

### 紧张状态等级 (T)

| 等级代码 | 标准分范围 | 名称 |
|----------|-----------|------|
| T0 | <50 | 良好 |
| T1 | 50-59 | 稍有波动 |
| T2 | 60-69 | 值得关注 |
| T3 | ≥70 | 建议关注 |

### 生活压力等级 (L)

| 等级代码 | LCU范围 | 名称 |
|----------|---------|------|
| L0 | <150 | 压力较低 |
| L1 | 150-300 | 有一定压力 |
| L2 | >300 | 压力较大 |

---

## 三维评估矩阵

### 基础等级计算表 (E × T → 等级)

```
           │  T0良好  │  T1稍有波动  │  T2值得关注  │  T3建议关注
───────────┼─────────┼───────────┼───────────┼──────────
E0 良好    │   1     │   2       │   3       │   4
E1 稍有波动 │   2     │   3       │   3       │   4
E2 值得关注 │   3     │   3-4     │   4       │   4-5
E3 建议关注 │   4     │   4       │   4-5     │   5
```

### 生活压力调整因子

在基础等级上，根据生活压力等级进行调整：

| 压力等级 | 调整规则 |
|---------|----------|
| L0 压力较低 | 基础等级 -0（保持不变） |
| L1 有一定压力 | 若基础等级≤2，则 +1 |
| L2 压力较大 | 若基础等级≤3，则 +1 |

**最终等级 = 基础等级 + 压力调整**

## 特殊关注机制

以下任一条件触发时，**等级 +1**（最高不超过等级5）：

### 关注条件1: 消极想法关注
- **触发条件**: 情绪评估第19题得分 ≥ 3
- **含义**: "活着对别人来说是个负担" - 选择"经常"或"持续"
- **说明**: 可能存在消极想法，值得关注

### 关注条件2: 情绪-紧张双指标偏高
- **触发条件**: 情绪标准分 ≥ 50 **且** 紧张标准分 ≥ 50
- **含义**: 情绪和紧张两个方面都偏高
- **说明**: 两个方面的状态叠加值得关注

### 关注条件3: 高压叠加效应
- **触发条件**: 
  - 生活压力高LCU事件(≥60)数量 ≥ 3项
  - 且 (情绪达到值得关注 OR 紧张达到值得关注)
- **含义**: 外部高压与内部状态相互影响

### 关注条件4: 持续性状态
- **触发条件**: 
  - 情绪评估中 ≥10题选择"经常"(3)或"持续"(4)
  - 或 紧张评估中 ≥10题选择"经常"(3)或"持续"(4)
- **含义**: 状态持续时间较长，影响范围大

## 综合评估等级详细定义

### 等级1: 状态良好

**典型特征**:
- 情绪: 良好 (<40), 紧张: 良好 (<50), 压力: 较低 (<150)

**表现**:
- 心理状态良好
- 无明显困扰
- 生活压力可控

**建议**:
- 保持健康生活方式
- 定期自我关怀
- 无需特殊干预

---

### 等级2: 稍有波动

**典型特征**:
- 任一模块达到稍有波动，其他良好/低压力

**表现**:
- 存在轻微情绪波动
- 可能有偶发的紧张或低落感
- 整体功能未受影响

**建议**:
- 注意情绪调节
- 保持规律作息
- 适度运动放松
- 增加社交活动

---

### 等级3: 值得关注

**典型特征**:
- 至少一个模块达到值得关注
- 或两个稍有波动模块叠加一定压力

**表现**:
- 有一定程度的困扰
- 状态可能影响日常生活
- 可能存在睡眠、食欲问题

**建议**:
- 学习放松技巧（冥想、深呼吸）
- 减少可识别的压力源
- 与亲友沟通感受
- 保证充足睡眠
- **建议2-4周内寻求专业咨询**

---

### 等级4: 建议调节

**典型特征**:
- 任一模块达到建议关注
- 或两个模块达到值得关注
- 或有特殊关注触发

**表现**:
- 状态值得关注
- 症状可能持续存在
- 社会功能可能受影响

**建议**:
- **建议寻求专业咨询**
- 可以考虑就诊评估
- 不要独自面对，告知信任的人
- 与专业人士聊聊

---

### 等级5: 建议关注

**典型特征**:
- 情绪建议关注 + 紧张值得/建议关注以上
- 或任何模块建议关注 + 压力较大
- 或消极想法关注已触发

**表现**:
- 状态需要关注
- 可能影响生活功能

**建议**:
- 建议寻求专业帮助
- 可以考虑心理咨询
- 与信任的人分享感受
- 保持社交联系

---

## 计算示例

### 示例1: 状态良好案例

```
输入:
  情绪原始分 = 28 (标准分35, E0=良好)
  紧张原始分 = 32 (标准分40, T0=良好)
  压力总分 = 95 (L0=压力较低)

计算过程:
  基础等级 = E0×T0 = 等级1
  压力调整 = L0 → 不变
  特殊关注检查: 全部未触发
  
输出结果: 等级1 (状态良好)
```

### 示例2: 稍有波动案例

```
输入:
  情绪原始分 = 38 (标准分48, E1=稍有波动)
  紧张原始分 = 44 (标准分55, T1=稍有波动)
  压力总分 = 200 (L1=有一定压力)

计算过程:
  基础等级 = E1×T1 = 等级3
  压力调整 = L1 → 已达等级3，无需调整
  
输出结果: 等级3 (值得关注)
建议: 关注并适当调节
```

## 评分标准

| 分值 | 含义 | 具体描述 |

| 1 | 偶或无 | 偶尔出现或完全没有该症状 |

| 3 | 经常 | 经常出现该症状（超过一半时间） |

## 计算方法

### 原始分计算

```
原始分 = 所有20题得分之和（反向题已转换）
```

### 标准分计算

```
标准分 = 原始分 × 1.25 (四舍五入取整)
```

**范围**: 25-100分

| 等级 | 原始分范围 | 标准分范围 | 紧张程度 | 说明 |

### 7. 睡眠状况 (题目: 19*, 20)

## 使用注意事项

### 施测前说明
1. 请根据**最近一周的实际感受**作答
2. 每题只能选一个答案
3. 不要遗漏任何题目
4. 第一反应为准，不要过度思考

### 结果解释原则
1. **本量表仅用于自我了解，不能替代专业诊断**
2. 高分结果提示可能需要关注自身状态
3. 结合日常表现和其他信息综合判断
4. 动态关注比单次测量更有价值
